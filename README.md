## Preguntas

1. **¿Qué es un pull request en GitHub?**

Es una petición formal que un desarrollador hace para incorporar cambios de código desde una rama secundaria (o un proyecto copiado) hacia la rama principal del proyecto.

Este permite que otros miembros del equipo revisen el código fuente, dejen comentarios, sugieran mejoras y discutan los cambios antes de fusionarlos definitivamente.

2. **¿Cómo se crea un pull request en GitHub?**

Para crear un Pull Request (PR) en GitHub, primero debes tener una rama (branch) con cambios que hayas subido (push) a tu repositorio.

Entra a GitHub y ve al repositorio principal donde quieres integrar el código. Si subiste la rama recientemente, verás un cartel amarillo arriba que dice "Compare & pull request". Haz clic en ese botón. Si el cartel no aparece, ve a la pestaña "Pull requests" y haz clic en el botón verde "New pull request".

3. **¿Cómo se aprueba un pull request en GitHub?**

Pasos para aprobar un Pull Request
- Entra al repositorio: Abre GitHub y ve al proyecto que deseas revisar.
- Abre la pestaña de solicitudes: Haz clic en Pull requests (Solicitudes de extracción) en la parte superior del repositorio.
- Selecciona el pull request: Busca en la lista la solicitud que quieres revisar y haz clic sobre ella.
- Revisa los cambios: Ve a la pestaña Files changed (Archivos cambiados) para leer las modificaciones de código.
- Abre el panel de revisión: Haz clic en el botón verde Review changes (Revisar cambios) en la esquina superior derecha.
- Aprueba el código: Selecciona la opción Approve (Aprobar), escribe un comentario opcional y haz clic en Submit review (Enviar revisión).
- Fusiona los cambios: Una vez aprobado, haz clic en el botón Merge pull request para unir los cambios a la rama principal.
